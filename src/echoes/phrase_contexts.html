How similarity is calculated

Search counts literal, non-overlapping matches within verse lines. Each context includes the matching line and one line on each side when available. Repeated passages are deduplicated within poems. The calculation masks the phrase, weights surrounding character 1–3-grams by TF-IDF, and averages normalized context vectors within poems. Each matching poem has equal weight in its poet’s vector. Comparison requires at least five matching poems and some surrounding wording to score.
